Stack & licenses

Everything this app is built with, grouped by role, with the license or attribution note for each piece. This page covers the Alex Rivers AWS re:Invent 2026 concierge, a demo built for the Napster API Ignite Hackathon.

Agent and voice

Napster API
Provides the agent, persona, knowledge base, functions, and realtime conversation behind Alex. Proprietary service. Used under the "Napster API - For Ignite 2026" Azure Marketplace pay-as-you-go plan taken out for the Ignite hackathon.
Napster Companion Web SDK
Renders the talking avatar in the browser and carries the voice conversation over WebRTC, with the green-screen silhouette composited over the app background. Proprietary SDK, used under the same Napster plan.
Azure OpenAI
The language model provider behind the agent, reached through Napster. Microsoft service, used under the Napster plan's provider configuration.
Napster webhooks and Sessions API
Session events and stored conversation data. The app uses them to rebuild captured introduction requests and meeting notes if the page is reloaded. Part of the Napster API, same plan as above.

Hosting and code

SpaceFast
Primary hosting for the live demo, including the static app and the serverless functions that mint Napster tokens and proxy the social feeds. Commercial hosting service, used under the author's account.
Microsoft Azure Static Web Apps
A mirror copy of the app, kept in step with the primary site. Free tier of the Microsoft service.
GitHub
Holds the public source repository. Pushes to the main branch redeploy the Azure mirror automatically. Commercial service, free tier. The app source itself is the author's own work.

UI kits

Web Awesome Pro 3.15.0
The component library and theme behind the cards, buttons, switches, and accordion sections. Commercial license. Served from the author's project kit, named "Alex Concierge".
Font Awesome Pro 7
All icons in the app, in the Sharp Duotone style, subset to the 28 icons the app actually uses. Commercial license. Served from the author's kit, named "Alex Concierge".

Maps and routing

Leaflet 1.9.4
The interactive map library for the venue and event map. Open source, BSD-2-Clause license. Copyright Leaflet contributors.
OpenStreetMap
The map tiles and geographic data for Las Vegas and the re:Invent campus venues. © OpenStreetMap contributors. Data available under the Open Database License (ODbL).
OSRM
Walking routes drawn on the map, computed with the foot profile. Open source, BSD-2-Clause license. Routes come from the public OSRM demo server.
Google Maps and MapQuest
Not embedded. Buttons in the app link out to directions in these services. Outbound links only; each service's own terms apply once you follow them.

Data sources

AWS Events API
The full re:Invent 2026 session catalog used by the agenda and near-me views: 2,869 sessions with times, venues, and rooms. Public AWS event data, read only. Session reservations and schedules were not touched.
AWS News Blog RSS
The AWS News headlines in the Social view. Public RSS feed from the AWS News Blog.
Bluesky public API
Live posts matching the re:Invent hashtags, via api.bsky.app. Public API. Posts remain the property of their authors.
X API
Live posts from X in the Social view, using recent search, plus geo search for posts near the visitor when they share their location. Developer tier access under the author's X developer account. Posts remain the property of their authors.

Media and design tools

Pexo
Generated the ambient Las Vegas background video loop that plays behind the avatar. AI video generation service, used under the author's paid account.
Adobe Firefly
A Generative Fill edit added the conference badge to the avatar portrait used in the app header and icons. Part of the author's paid Adobe subscription.
Google Stitch
Used during design to explore the mobile layouts, including the bottom tab bar and the cyberpunk variant. Design exploration tool. The shipped interface was hand-built in this codebase, informed by those mockups.
